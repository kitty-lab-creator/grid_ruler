# 方格紙量尺 (Grid Ruler) — 1:1 Physical Screen Ruler & Calibrated Graph Paper

> **將任何手機、平板或筆電螢幕，瞬間轉化為 100% 精準的 1:1 實物工程量尺。**
> 專為隨時隨地測量隨身物件、螺絲、文具、零件設計，免安裝、免連網、支援全離線運作與加到主畫面。

---

## 🧐 為什麼你需要這款量尺？（Why Calibrated Screen Ruler?）

你是否曾在手機或電腦上搜尋「線上量尺」，卻發現量出來的公分或英吋**根本不準**？
- **原因**：每台手機（iOS、Android、平板或筆電）的螢幕解析度與像素密度（PPI / DPI）完全不同。如果軟體沒有校準，螢幕上的 1cm 往往比真實的 1cm 偏大或偏小 10%~30%。
- **我們的解決方案**：**「實體卡片 1:1 物理校準法」**。拿出皮夾裡任何一張標準尺寸的卡片（信用卡、八達通、健保卡、悠遊卡、會員卡），貼在螢幕上對齊 3 秒，即可讓螢幕上的方格紙與實物公分/英吋達成 **100% 絕對精度**！

## ✨ 核心特色與功能（Key Features）

- 🎯 **1:1 物理實卡精準校準（Physical Card Calibration）**
  - 使用國際標準 ISO/IEC 7810 ID-1 規格（高 53.98mm）作為物理基準線。
  - 只需貼上卡片對齊紅色標示線，即可消除任何裝置的顯示公差。
  - 亦提供手動 PPI 數值微調與一鍵還原系統預設值。

- 📐 **互動式十字游標（Interactive Crosshair Guide）**
  - 開啟實線十字游標，任意拖曳至物體邊緣。
  - 畫面即時顯示 X 軸寬度、Y 軸高度以及 **斜邊長度（對角線）**，不規則物件也能輕鬆測量。

- 📏 **雙單位一鍵切換（Metric / Imperial）**
  - **公制（cm / mm）**：每 1mm 一小格、每 5mm 一中格、每 1cm 粗線附帶清楚數字標記。
  - **英制（in / fraction）**：每 1/8 英吋一小格、每 1/4 英吋中格、每 1 英吋主刻度標記。

- 🎨 **4 種專業工程與護眼底色（Color Themes）**
  - 經典極簡白（Default White）
  - Tajima 捲尺工程黃（High-Contrast Construction Yellow）
  - 50% 中性專業灰（Neutral Gray）
  - 靜謐夜間深黑（OLED Deep Dark）

- 📱 **全平台防拉伸與自適應（Full-Device Compatibility）**
  - 經 Android 與 iOS 裝置完整實機測試，在螢幕旋轉、直橫向切換時均進行像素級嚴格鎖定，保證方格永遠為完美正方形，杜絕變形。

- ⚡ **100% 離線運作 & 安裝到主畫面（Full Offline Support）**
  - 不需網路、無廣告、零後端追蹤，所有校準數據自動保存在本機裝置。
  - 支援「加入主畫面」，點開即用，如同原生專屬量尺工具。

## 🚀 快速上手教學（How to Use）

1. **直接開啟網頁**
   - 瀏覽器開啟應用程式，量尺將自動根據裝置型號載入初始尺寸。
2. **進行一次性實物校準（強烈建議）**
   - 點擊右側工具列的 **💳 信用卡校準按鈕**。
   - 拿出你的信用卡/八達通/悠遊卡貼在螢幕右側預覽圖上。
   - 點擊「縮小高度」或「放大高度」，使紅色頂底雙標線剛好緊貼卡片邊緣，最後點擊 **「完成校準 ✓」**。
3. **開始測量**
   - 將待測物品（如螺絲、戒指、耳機、文具）放在螢幕上。
   - 點擊右側的 **十字游標按鈕** 拖曳線條，精準讀取物體的寬度、長度與對角線。

## 📲 如何安裝至手機主畫面（Install as App）

- **iPhone / iPad (Safari)**：
  1. 點擊瀏覽器底部的 **「分享」** 按鈕（向上箭頭）。
  2. 向下滑動並選擇 **「加入主畫面（Add to Home Screen）」**。
- **Android (Chrome)**：
  1. 點擊瀏覽器右上角的 **「選單（三個點）」**。
  2. 選擇 **「安裝應用程式」** 或 **「加到主畫面」**。
