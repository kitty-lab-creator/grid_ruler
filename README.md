## 🚀 如何在 GitHub 免費開啟你的專屬網站 (GitHub Pages 設定指南)

當你在 GitHub 上只看到代碼與這份說明文件時，請依照下列步驟開啟網頁：

1. 點擊本 GitHub 儲存庫上方的 **Settings** (設定，齒輪圖示)。
2. 在左側選單中找到並點選 **Pages**。
3. 在 **Build and deployment** 底下的 **Source** 下拉選單中，選擇 **GitHub Actions**。
4. 儲存後，GitHub 會自動執行本專案內建的部署流程（約 1 分鐘）。
5. 部署完成後，頁面最上方即會顯示你的專屬網址：`https://<你的用戶名>.github.io/grid_ruler/`！

## 📱 手機加到主畫面 (PWA 專屬獨立 App)

- **iPhone (iOS Safari)**：開啟網頁後，點擊瀏覽器下方「分享」按鈕 (方形帶箭頭) ➔ 選擇「加入主畫面」。
- **Android (Chrome)**：開啟網頁後，點擊右上角「三點選單」 ➔ 選擇「安裝應用程式」或「加到主畫面」。

## ✨ 核心特色

- **Tajima 工業捲尺黃**：高飽和度 Tajima 捲尺經典工程黃底色，搭配極致高對比刻度。
- **50% 標準灰 (18% / 50% Neutral Grey)**：標準中性 50% 灰色，提供精確不反光的視覺背景。
- **純實線十字參考線**：清晰的紅色實線與十字游標，搭配即時浮動尺寸數值。
- **1:1 實體卡片快速校準**：以身邊任何標準信用卡、八達通卡或健保卡貼在螢幕上微調，高度完全精準吻合。
- **全離線支援**：只需校準一次，手機自動長久記憶，無網路環境隨時可用。
